Firebase配置與房間管理系統

📖 Firebase設定說明： 請按照以下步驟設定Firebase，以啟用線上房間功能。
1 建立Firebase專案

前往 Firebase控制台 並建立新專案：

  • 點擊「新增專案」
  • 輸入專案名稱（例如：trade-route-calculator）
  • 選擇是否啟用Google Analytics（建議不啟用以簡化設定）
  • 點擊「建立專案」
2 設定Firestore資料庫

在Firebase控制台中：

  • 在左側選單中點擊「Firestore Database」
  • 點擊「建立資料庫」
  • 選擇「以測試模式啟動」
  • 選擇資料庫位置（建議選擇asia-east1或離您最近的區域）
  • 點擊「完成」
3 取得Firebase設定

在Firebase控制台中：

  • 點擊左上角的專案設定圖示（齒輪圖標）
  • 選擇「專案設定」
  • 向下滾動到「您的應用程式」部分
  • 點擊「新增應用程式」並選擇「Web」
  • 輸入應用程式暱稱（例如：trade-calculator-web）
  • 點擊「註冊應用程式」
  • 複製提供的Firebase設定代碼
4 輸入Firebase設定

將從Firebase獲取的設定代碼貼到下方表單中：

Firebase 設定
5 安全規則設定（可選）

若要加強安全性，可以在Firestore中設定規則：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomId} {
      allow read, write: if request.time < timestamp.date(2025, 12, 31);
    }
  }
}

這將允許在2025年底前對房間進行讀寫操作。您可以根據需要調整規則。

大貿易節路線計算機

這是一個專為「異世界奇妙生活」遊戲設計的貿易路線計算工具。

主要功能：

  • 📊 貿易數據輸入與管理
  • 🎯 智能路線計算（最多7段貿易路線）
  • 🏠 線上房間系統（多人協作）
  • 📱 響應式設計（支援手機和電腦）
  • 💾 本地與雲端數據儲存

技術規格：

  • 前端：HTML5, CSS3, JavaScript
  • 後端：Firebase Firestore（雲端資料庫）
  • 儲存：本地儲存 (localStorage) 與雲端同步
  • 相容性：所有現代瀏覽器

版本資訊：

  • 當前版本：v2.0.0
  • 更新日期：2023年11月
  • 開發者：異世界奇妙生活社群
疑難排解

常見問題與解決方法：

Q: Firebase連線失敗

A: 請檢查Firebase設定是否正確，並確認網路連線正常。

Q: 房間功能無法使用

A: 請確認已正確設定Firebase，並且Firestore資料庫已建立。

Q: 數據無法同步

A: 請檢查瀏覽器是否支援localStorage，並嘗試清除瀏覽器快取。

Q: 如何備份數據

A: 數據會自動儲存在本地和雲端。您也可以使用「儲存所有數據」按鈕手動備份。
