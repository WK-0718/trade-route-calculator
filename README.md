## 🗺️ 路線類型說明

### 1. ⭐ 推薦路線
**特點**：所有分段收益率均 ≥ 26%，最安全穩定

**適用情況**：
- 追求穩定收益

**顯示示例**：
```
排名 | 路徑 | 平均收益 | 分段收益 | 物品追蹤
1 | 龍城→精靈之森→珊瑚區 [3段] | 38.5% | 35.2%•41.8% | 櫻花→櫻花•回音海螺→回音海螺
```

### 2. 🔁 循環路線
**特點**：起點終點物品相同，可無限循環，可能包含低收益分段

**適用情況**：
- 想要重複刷收益
- 能接受部分低收益分段
- 超多體力（重複刷+每段都選擇10倍）

**特殊標記**：
- 🔴 紅色數字：收益率 < 26% 的分段

### 3. ➡️ 單程路線
**特點**：起點終點物品不同，所有分段 ≥ 26%

**適用情況**：
- 體力不多,追求一次性高收益貿易
- 解急需任務首選（拿SR夥伴默克）
- 補充收益選擇

## 🧮 計算原理

### 收益率計算公式
```javascript
收益率 = (賣出價格 - 買入價格) ÷ 買入價格 × 100%

// 舉例：
買入價格：80%，賣出價格：115%
收益率 = (115 - 80) ÷ 80 × 100% = 43.75%
```

### 多段路線平均收益
```javascript
平均收益率 = (分段1收益率 + 分段2收益率 + ...) ÷ 分段數量
```

### 路線連接規則
1. **物品匹配**：前一段賣出物品 = 後一段買入物品
2. **地點唯一**：同一路線中地點不重複
3. **段數限制**：最多7段貿易（8個地點）
4. **收益要求**：推薦路線每段 ≥ 26%

## ❓ 常見問題

### Q1: 為什麼計算後沒有顯示任何路線？
**可能原因**：
- 價格數據未輸入或為0
- 沒有符合收益率 ≥ 26% 的路線
- 物品選擇無法形成連續路線

**解決方案**：
1. 檢查所有價格是否正確輸入
2. 調整賣出物品選擇
3. 確認買入/賣出價格都有數值

### Q2: 循環路線中的紅色數字是什麼意思？
**答案**：紅色標記表示該分段收益率低於26%，雖然整體路線可能仍有價值，但需要玩家自行評估風險。

### Q3: 最多支持多少段路線？
**答案**：最大7段路線（8個地點），這個限制平衡了計算效能與遊戲實用性。

### Q4: 數據會保存多久？
**答案**：數據永久保存在瀏覽器本地儲存中，直到：
- 手動清除瀏覽器數據
- 點擊「清除所有」按鈕
- 更換瀏覽器或設備
