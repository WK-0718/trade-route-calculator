## 🎯 專案簡介

「大貿易節路線計算機」是專為手機遊戲《異世界奇妙生活》中的《大貿易節》活動設計的智能貿易路線分析工具。透過計算各貿易地點的買入賣出價格，自動計算貿易路線，幫助玩家最大化貿易收益。

## ✨ 功能特色

### 🔥 核心功能
- **智能路線計算**：自動計算貿易路線
- **實時數據同步**：多人協作編輯貿易數據
- **房間系統**：創建/加入房間共享數據
- **本地儲存**：離線使用，數據不遺失
- **響應式設計**：支援電腦和手機瀏覽

### 🕒 自動化管理
- **24小時自動清理**：閒置房間自動刪除
- **實時用戶列表**：顯示房間內在線用戶
- **數據版本控制**：避免數據衝突

## 🚀 快速開始

### 第一步：開啟應用
1. 在瀏覽器中開啟大貿易節路線計算機網頁
2. 系統會自動初始化並載入本地數據

### 第二步：選擇使用模式
- **💾 本地模式**：個人使用，數據儲存在瀏覽器
- **🏠 創建房間**：與朋友共享數據，實時同步
- **🚪 加入房間**：輸入房間代碼加入現有房間

### 第三步：開始計算
1. 輸入貿易價格數據
2. 點擊「🚀 開始計算7段路線」
3. 查看貿易路線

## 📚 詳細使用教學

### 1. 數據輸入教學

#### 基本操作
1. 在表格中找到對應的貿易地點（共25個地點）
2. 輸入「買入價格%」和「賣出價格%」
3. 從下拉選單選擇要賣出的物品
4. 點擊該行的「💾 儲存」按鈕保存數據

#### 批量操作
- **💾 儲存所有數據**：一次性保存所有修改
- **🗑️ 清除所有數據**：重置所有價格為0（需確認）

#### 價格輸入技巧
- **價格範圍**：0% - 200%
- **系統過濾**：自動忽略價格為0的地點
- **重要提示**：只有輸入有效價格的地點才會參與路線計算

### 2. 路線計算教學

#### 開始計算
1. 確保已輸入足夠的貿易數據（建議至少5個地點）
2. 點擊「🚀 開始計算7段路線」按鈕
3. 等待系統分析計算（通常需要2-5秒）
4. 查看計算結果

#### 結果解讀
計算完成後會顯示三類路線：

**⭐ 推薦路線**
- 所有分段收益率均 ≥ 26%
- 按平均收益率從高到低排序
- 顯示路徑、平均收益、分段收益

**🔁 循環路線**
- 起點和終點物品相同
- 可以無限循環交易
- 特別適合長期貿易

**➡️ 單程路線**
- 起點和終點物品不同
- 適合一次性貿易
- 顯示完整交易鏈

### 3. 介面操作教學

#### 電腦/手機切換
- 點擊右下角的「💻」按鈕切換介面模式
- **電腦模式**：完整表格顯示，適合大螢幕
- **手機模式**：響應式設計，適合小螢幕

## 🏠 房間功能說明

### 創建房間
1. 點擊「🏠 創建房間」按鈕
2. 輸入房間名稱和您的暱稱
3. 系統會自動生成房間代碼
4. **房間代碼會自動複製到剪貼板**
5. 將房間代碼分享給朋友

### 加入房間
1. 點擊「🚪 加入房間」按鈕
2. 輸入您的暱稱和房間代碼
3. 或從現有房間列表中選擇
4. 點擊「加入房間」即可進入

### 房間功能
- **實時同步**：所有用戶的修改會立即同步
- **用戶列表**：顯示房間內所有在線用戶
- **離開房間**：隨時可以離開房間
- **關閉房間**：只有房間創建者可以關閉房間

### 房間自動清理
- **24小時規則**：房間最後活動時間超過24小時自動刪除
- **活動更新**：任何數據修改都會更新活動時間
- **用戶通知**：如果房間被刪除，用戶會收到通知

## 📊 路線計算規則

### 收益率計算公式
```
分段收益率 = (賣出價格 - 買入價格) ÷ 買入價格 × 100%
平均收益率 = 所有分段收益率總和 ÷ 分段數量
```

## 💡 使用模式說明

### 本地模式 (推薦個人使用)
**優點：**
- 數據永久保存於瀏覽器
- 離線可用
- 加載速度快

**缺點：**
- 無法與他人共享數據
- 更換設備時數據不會同步

### 房間模式 (推薦團隊使用)
**優點：**
- 多人協作輸入數據
- 實時同步更新
- 減少重複工作

**缺點：**
- 房間有24小時時效限制

## ❓ 常見問題

### Q1: 為什麼計算後沒有顯示任何路線？
**可能原因：**
- 輸入的價格數據不足
- 所有分段收益率都低於26%
- 沒有找到符合條件的物品連接

**解決方法：**
- 檢查並輸入更多地點的價格
- 確認買入賣出價格設置正確
- 嘗試調整賣出物品的選擇

### Q2: 房間突然消失了怎麼辦？
**原因：**
- 房間超過24小時沒有活動被自動刪除
- 房間創建者關閉了房間

**解決方法：**
- 創建新的房間並重新輸入數據
- 切換到本地模式繼續使用

### Q3: 如何確保數據不會遺失？
**建議做法：**
- 定期點擊「💾 儲存所有數據」
- 重要數據可以截圖保存
- 考慮使用房間模式多人備份

### Q4: 為什麼有些路線顯示為紅色？
**顏色說明：**
- 🔴 **紅色**：平均收益率 > 30%（高收益）
- 🟠 **橙色**：平均收益率 26-30%（中等收益）

### Q5: 最多可以有多少人同時使用一個房間？
**技術限制：**
- 理論上沒有限制人數
- 建議不超過10人以保持同步效率
- 所有用戶都可以同時編輯數據
